Home Assistant Integration

  1. Öffnen Sie HACS (Home Assistant Community Store) in Ihrer Home Assistant-Instanz.
  2. Klicken Sie auf die drei Punkte (oben rechts) und wählen Sie Benutzerdefinierte Repositories.
  3. Fügen Sie https://github.com/pkreissel/temperature-crowd-hacs mit der Kategorie Integration hinzu.
  4. Suchen Sie in HACS nach TemperaturCrowd und klicken Sie auf Herunterladen.
  5. Starten Sie Home Assistant neu.
  6. Navigieren Sie zu Einstellungen > Geräte & Dienste > Integration hinzufügen, suchen Sie nach TemperaturCrowd und folgen Sie der Einrichtung.
